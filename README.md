# Banco Digital com Java e Orientação a Objetos

Projeto desenvolvido para o desafio da plataforma DIO
**Criando um Banco Digital com Java e Orientação a Objetos**.

## Objetivo

Aplicar os principais conceitos de Programação Orientada a Objetos
utilizando Java através da implementação de um banco digital.

## Conceitos utilizados

- Abstração
- Encapsulamento
- Herança
- Polimorfismo

## Funcionalidades

O sistema permite:

- Criar clientes
- Criar conta corrente
- Criar conta poupança
- Realizar depósitos
- Realizar saques
- Realizar transferências
- Consultar extrato
- Listar contas do banco
